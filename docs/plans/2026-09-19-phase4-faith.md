# Фаза 4 «Вера»: пантеоны, храмы, жертвы, благословения, чудеса, артефакты

**Цель:** дать моду долгосрочную цель, которой у него нет. Колония сейчас
кончается на четвёртой ступени ратуши: дальше строить нечего, копить
незачем. Вера — это то, ради чего играют ещё двадцать вечеров.

**Опора:** дизайн-документ, раздел «Боги и чудеса» и фаза 4; решения
заказчика от 2026-09-10 («боги независимы», «благосклонность набирается
медленно»).

---

## Что именно строим

Один замкнутый круг, в котором каждое звено уже можно потрогать:

**храм → алтарь → жертва → благосклонность → благословение / чудо / артефакт**

Не «пантеон вообще», а работающая петля: игрок строит храм, кладёт
на алтарь то, что у него есть, видит, как растёт число, и на четвёртой
ступени получает вещь, которой нельзя добыть ничем другим.

---

## Общие ограничения

- **Кодек поселения.** В главной группе ровно шестнадцать полей, занято
  пятнадцать. Вся вера обязана уместиться в **одно** вложенное поле
  `Settlement.Faith` — как когда-то уместилась война.
- **Домен бога — включатель кода, а не данные.** По тому же правилу, что
  и черта народа: данные умеют назвать число, но не умеют объяснить
  движку, что «билдер кладёт блок быстрее». Список доменов в коде
  закрытый, датапак выбирает из него.
- **Боги независимы** (решение заказчика): жертва одному не злит другого.
- **Благосклонность набирается медленно** (решение заказчика): за
  прохождение игрок успевает поднять одного-двух богов, и выбор остаётся
  за счёт нехватки времени, а не наказания.
- **Отказ обязан говорить причину.** Правило мода, заработанное кровью:
  молчащая кнопка неотличима от поломки.
- Каждый новый блок проходит `BlockResourcesTest`; каждый новый тест
  доказывается поломкой.

## На что смотреть в приёмке

1. **Жертву нельзя завалить стопкой.** Бог принимает одну жертву в день;
   иначе сундук пшеницы покупает избранничество за минуту.
2. **Благословение обязано быть видно в игре**, а не только числом
   в пульте: быстрее растёт хлеб, быстрее встаёт стена, меньше приходит
   налётчиков.
3. **Артефакт выдаётся один раз.** Потратил благосклонность — артефакт
   остаётся; перезашёл в мир — второго не дают.
4. **Чужой храм не ломается молча.** Алтарь чужой деревни говорит, что
   здесь можно, а не проглатывает нажатие.
5. **Два бога одного народа не принимают одну жертву.** Иначе «что кладёшь
   — тому и молишься» перестаёт быть правилом.

## Задача 1: бог как данные

**Файлы:**
- Создать: `core/faith/God.java`, `core/faith/Domain.java`, `core/faith/Gods.java`
- Изменить: `VillagePax.java` (регистрация загрузчика)
- Данные: `data/villagepax/villagepax/gods/norman_*.json`, `maya_*.json`

Бог описывается датапаком целиком, кроме действия:

```json
{
  "culture": "villagepax:norman",
  "display_name": "villagepax.god.norman.sower",
  "domain": "harvest",
  "offerings": { "minecraft:wheat": 3, "minecraft:bread": 5, "villagepax:cloth": 9 },
  "artifact": "villagepax:sickle_of_plenty"
}
```

- [ ] `Domain` — перечисление: `HARVEST`, `STONE`, `WATCH`. Кодек через
      `EnumCodecs.of`, как у роли здания: описка обязана называться
      в логе, а не молча давать умолчание.
- [ ] `God` — запись с кодеком; поле `domain` **обязательное**.
- [ ] `Gods extends JsonDataLoader` — по образцу `TradeTables`, папка
      `villagepax/gods`. Ключ — опознаватель файла (богов у народа
      несколько, ключом культура быть не может).
- [ ] `Gods.of(culture)` — пантеон народа, отсортированный по домену.
- [ ] Шесть файлов: три норманнских, три майяских.

## Задача 3: ступени и жертва

- [ ] Проверка целостности данных: два бога одного народа не принимают

## Задача 5: благословения и чудеса

**Файлы:** `sim/faith/Blessings.java`, `sim/faith/Miracles.java`
+ врезки в `BuilderJob`, `Raids`, `WorkTicker`

- [ ] `Blessings.invoke(colony, domain, today)` — стоит 60 очков, держится
      3 дня. Отказ называет причину.
- [ ] **Урожай** — суточный тик доращивает посевы на полях колонии.
- [ ] **Камень** — билдер кладёт на блок больше за решение.
- [ ] **Дозор** — отряд налётчиков меньше на бойца (но никогда до нуля:
      набег, который не приходит, — выключенная механика).
- [ ] `Miracles.call(colony, domain, today)` — стоит 200 очков, разовое:
      дождь / исцеление жителей / гнев на осаждающих.

## Задача 8: проверки

Каждая доказывается поломкой:

- [ ] Жертва поднимает благосклонность, вторая в тот же день — нет.
- [ ] Бог принимает только своё; чужая вещь названа отказом.
- [ ] Два бога одного народа не делят жертву (целостность данных).
- [ ] Благословение дозора убавляет отряд, но не до нуля.
- [ ] Благословение камня ускоряет билдера.
- [ ] Артефакт выдаётся один раз и остаётся после траты очков.
- [ ] Алтарь чужой деревни отказывает словами.
- [ ] У каждого бога артефакт существует предметом.
- [ ] У каждой культуры с храмом есть пантеон.
