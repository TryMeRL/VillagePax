## Жалобы заказчика

- [x] (cd2ca0b) **«15 одинаковых имён скучно видеть»** — имена жителей повторяются.
  Причина найдена: в `name_pools` каждого народа всего 6–8 имён на пол
  (`data/villagepax/villagepax/cultures/*.json`), а `Founding.newCitizen`
  берёт случайное без оглядки на уже живущих. В колонии из 15 человек
  повтор неизбежен (7 мужских имён на ~8 мужчин). Лечение:
  1. именники по 40–60 имён на пол у каждого из 7 народов;
  2. выбор имени — сперва из не занятых в поселении (и, по возможности,
     в мире), только потом повтор;
  3. у повторившегося — прозвище/родовое имя («Рольф Кузнец», «Рольф
     с мельницы»), чтобы два Рольфа различались;
  4. названия деревень (6–7 на народ) — тоже расширить и не повторять
     в мире: две «Кан» на карте путают компас `/villagepax locate`.

## Баги (найдено чтением)

- [x] (1c744a8) **Осада стирает поход колонии.** `Settlement.restFor/besiege/
  updateSiege/liftSiege/beaten/makeAlly/breakAlly` собирают `War`
  7-аргументным конструктором, который ставит `marchingOn = empty`.
  Колонии, чья стража ушла в поход, достаточно получить набег (или
  отряд у ворот поредеет) — и запись «в походе» исчезает. Последствия
  смотреть в `Campaigns`. Лечение: везде через «with»-методы `War`,
  сохраняющие все поля; модульный тест «каждая правка War не теряет
  остальных полей».
- [x] (1c744a8) **Купца обоза можно убить «руками мира» без штрафа.** `Caravans.robbed`:
  штраф −25 только при `killer != null`, а это лишь прямой удар игрока.
  Лава, кактус, падение, утопление → товар и кошель высыпаются, доверие
  не меняется. Лечение: виновник — `body.getAttackingPlayer()` (кто бил
  последние 5 с), иначе ближайший игрок в 16 блоках; если рядом никого —
  товар не высыпается, а «уезжает домой» (возвращается на склад деревни).

- [x] (1c744a8) **КЛОНЫ ЖИТЕЛЕЙ (критично, возможно и есть «15 одинаковых имён»).**
  `CitizenSpawner` слушает `ENTITY_UNLOAD` и зовёт `writeBackTo`, который
  обнуляет `entityUuid` в записи. Но это событие приходит не только при
  выгрузке: тело, зашедшее в секцию сущностей без слежения (край
  прогрузки), получает `stopTracking` — тело живо, а запись про него
  забыла (см. память «Bodies unlink», чип так и не сделан). Дальше:
  `hasLiveBody` = ложь → при следующей загрузке чанка места записи
  рождается **второе тело** того же жителя; старое бродит с прежней
  целью и тем же именем над головой, стратегия его не ведёт. Хуже:
  если сироту убьют — `buryCitizen` удалит запись живого жителя.
  Лечение: событие выгрузки различать по `getRemovalReason()` (null —
  тело живо, только ушло из слежения → ничего не трогать); на
  `ENTITY_LOAD` своего тела с чужим/пустым `entityUuid` — перепривязать
  или убрать лишнее; `onChunkLoad`/`hasLiveBody` должны находить тело
  по `citizenId`, а не только по записанному UUID; сирота (тело, чья
  запись указывает на другое тело) — `discard()` без записи и без похорон.
  Проверка: игровой тест «тело ушло в секцию без слежения и вернулось —
  тело одно, запись указывает на него».

- [x] (68e4ab4) **Иконка ремесла в пульте только у 6 ремёсел** —
  `TownHallScreen.toolOf`: builder/courier/farmer/lumberjack/guard/elder;
  ткач, пивовар, купец, затейник, жрец и прочие — хлебная корка.
  Брать значок из данных ремесла (поле `icon` в `professions/*.json`).
- [x] (68e4ab4) **Жёлтое «настроение» на светлой бумаге** — `TownHallScreen.colorOf`
  даёт `0xD0C070` для всего, что не «доволен» и не «голоден»: светло-жёлтый
  текст на пергаменте почти не читается. Нужен тёмный янтарь (`Look.GOLD`).

- [x] (1c744a8) **Клоны и сироты бьют дальше, чем казалось.** Всё, что ищет тело
  по `citizen.entityUuid()` (`WorkTicker.liveBody`, `Company.body`,
  `Life.discardBody`, `Needs.leave`), сироту не видит: умерший от
  старости или ушедший житель оставляет **живое тело-призрак** с его
  именем, которое бродит по деревне вечно (тела не сохраняются, но до
  выгрузки чанка — бродит). Лечится тем же исправлением клонов: поиск
  тела по `citizenId`, а при смерти/уходе — убрать все тела этого жителя.
- [x] (1c744a8) **Поход: стража может «вернуться» сама.** Плюс: убитый в походе страж проходил веткой «кукла набега» (`Raids.fell`) и его запись не удалялась — воскресал дома. Пока колония в походе,
  ей может прийти чужой набег (`Raids.sendIfDue` проверяет только
  `siege()`), `besiege` на колонии стирает `marchingOn` (баг War выше) →
  `Campaigns.isAway` ложь → стража у чужих стен снова получает решения
  «патрулировать дом». Входит в задачу War.
- [x] (cd2ca0b) **Переселенец из квеста бессмертен.** `Quests.settle` не зовёт
  `Ages.arrivedGrown` — запись остаётся `UNAGED`, житель не стареет
  и не умирает никогда (пришлые через `Housing` получают возраст).
  Ещё: кровать и мастерская ему не раздаются до рассвета.
- [x] (68e4ab4) **Ремесленник варит со скоростью станка-автомата.** `CraftJob`
  делает рецепт на каждом решении у станка — раз в 10 тиков: стак
  пшеницы превращается в эль за ~10 секунд, шерсть в сукно так же.
  Работа должна быть видна и занимать день — нужна пауза между
  варками (~одна в 5–6 с), склад перестанет «исчезать» на глазах.
- [x] Мелочи пульта/сети: заказ запертого здания теперь отвечает; `removeStack(int)` помечает склад; `GamesNet` — порядок верный (снимок глазами игрока). Было: `TownHallNet.order`
  молчит о `Result.Locked`; `TownHallBlockEntity.removeStack(int)` без
  `markDirty`; `GamesNet.viewOf` — порядок `won/lost` сверить с `Rivalry`
  (счёт хранится «глазами жителя»).

## План работ

Порядок — по тому, что игрок почувствует сильнее. Каждый пункт: тест
(модульный или игровой) → правка → прогон `runGametest` (`_JAVA_OPTIONS=-Xmx2G`)
→ коммит.

1. [x] **Имена**: именники ×7 народов (по 40+ на пол, 15+ деревень);
   `Founding` выбирает незанятое в поселении имя, повтор — с отчеством/
   прозвищем; дети пары не получают имён братьев/сестёр и родителей;
   деревни мира — без повторов названия. Тест: 30 жителей одного народа
   — без одинаковых полных имён.
2. [x] **Клоны/сироты**: выгрузку тела отличать по причине удаления;
   тело ищется по `citizenId`; лишнее тело — `discard`; при смерти/уходе
   убирать все тела жителя. Игровой тест на unlink.
3. [x] **War**: `with`-методы, сохраняющие все поля; модульный тест.
4. [x] **Обоз**: виновник — бивший игрок, иначе ближайший в 16 блоках,
   иначе товар возвращается домой.
5. [x] **Квестовый переселенец**: возраст, кровать, мастерская.
6. [x] **Ремесленник**: пауза между варками.
7. [x] **Пульт**: значки ремёсел из данных, цвет настроения.
8. [x] **Биомы**: расширить дома народов на пустые биомы.
